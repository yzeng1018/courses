3.1 — 快手巴西增长

一条不平滑的增长线

快手巴西DAU从几百万到2500万，用户时长从20分钟涨到70分钟。

中间有几个关键拐点，每个拐点都是一个产品或运营决策带来的。

今天讲的不是"增长黑客"的技巧，是增长飞轮的设计——如何让增长变成自我强化的系统。

3.1 — 滴滴巴西

出行平台的增长飞轮

→ 更多司机
→ 接单速度更快
→ 用户体验更好
→ 更多用户 → 更多订单
→ 司机收入更高 → 更多司机 ↺

启动条件：足够的司机密度。高峰期等待 <3分钟，飞轮才转得起来。

4

3.1 — 快手巴西

内容平台的增长飞轮

→ 更多优质内容
→ 推荐效率更高
→ 用户时长更长
→ 创作者收益更高
→ 更多创作者 → 更多优质内容 ↺

启动条件：足够的优质内容。刷10条有8条是垃圾，用户就走了。

5

3.1 — 关键转折点

飞轮转起来的标志

出行平台

  • 自然增长占比 > 付费获客
  • 用户开始自己推荐给朋友
  • 付费获客成本开始下降

内容平台

  • 创作者投稿率自然上升
  • 不完全依赖补贴
  • 用户时长持续增长

3.2

第二节

内容生态：
从"有内容"到"有好内容"

7

3.2 — 核心判断

增长的天花板不是获客，
是内容供给

  • 花钱买来100万用户，内容不好，七日留存可能只有10%
  • 内容质量好，自然传播和口碑就能带来持续增长
  • 我们做增长的第一件事不是投广告，是治理内容质量
8

3.2 — 四步体系

快手巴西内容运营体系

01 内容质量打分 + 分级分发 — AI给每条内容打0-100分，高质量获大分发池
02 双列改单列 — 最大的产品决策，用户时长从20+分钟涨到45分钟
03 创作者激励正循环 — 投稿率从2%涨到6%，内容池指数级增长
04 新闻二创 + 小剧场 — 差异化打法，TikTok没做的我们做了
9

3.2 — 最大决策

双列改单列：数据说话

快手的DNA是双列瀑布流。改单列 = 说"我们在巴西不做快手，做TikTok"。

我顶着巨大的内部压力改了。

改前

  • 双列瀑布流
  • 用户时长 20+ 分钟

改后

  • 单列沉浸式
  • 用户时长 → 45 → 70 分钟
10

3.2 — 创作者生态

创作者激励的正循环

→ 补贴激励 → 投稿量上升
→ 内容池变大 → 推荐系统更精准
→ 用户时长上升 → 广告收入上升
→ 有更多钱做补贴 ↺

投稿率 2% → 6%，听起来不多，但对内容池的影响是巨大的。

3.3 — 三驾马车

买量 + 裂变 + 品牌

💰

买量（付费获客）

Google/FB基本盘 + Ad Network低成本拓展，联合AppsFlyer建反作弊和助攻体系

🔗

裂变（社交传播）

Panini世界杯集卡 → DAU冲峰值。核心：简单，巴西用户对复杂规则没耐心

⭐

品牌（长期心智）

签约巴西国家队、内马尔代言。不是短期ROI，但对留存和口碑影响巨大

13

3.3 — 组织协同

裂变和买量合成一个团队

合并前

  • 两个团队各自为战
  • 互相竞争同一批用户
  • 裂变素材和买量素材重复

合并后

  • 统一策略，避免内耗
  • 裂变素材复用给买量
  • 协同效率大幅提升

3.3 — 增长停滞

DAU不涨了，怎么办？

DAU到了一个数之后就不涨了。投更多广告也不涨。

原因：不是获客能力不够，是内容供给到了瓶颈。

解法：回到内容治理。提升内容质量 → 提升留存 → 自然增长恢复。

但真正的答案往往是
"回到产品本身"。
